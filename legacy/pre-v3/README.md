# Pre-v3 implementation archive

These superseded custom modules are preserved for reference, not loaded by the
application. The September 2026 team v3 release owns Overview, KPI dashboards,
forecasting, scenario planning, AI and calculation documents. Only the Atlas
digital twin is carried forward into the active frontend.

The tests and scripts here target the retired implementation; run the active
tests under `netgravity/tests` and `scripts/test-atlas-workspace.mjs` instead.
Restore individual features deliberately, not by importing this archive.
The archive is excluded from deployment images.
