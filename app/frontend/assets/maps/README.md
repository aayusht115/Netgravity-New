# Geographic relief

`natural-earth-mercator.webp` is Natural Earth I, 1:50m, shaded relief with water,
version 3.2.0. Source: https://www.naturalearthdata.com/downloads/50m-raster-data/50m-natural-earth-1/
Archive: https://naciscdn.org/naturalearth/50m/raster/NE1_50M_SR_W.zip
Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

Reprojected from equirectangular into EPSG:3857, 4096 × 4096; longitude
−180…180, latitude −85.0511287798066…85.0511287798066. Rebuild with
`scripts/build-atlas-assets.mjs`. Both map views sample this same projection.
Relief is illustrative geographic context, not routing, elevation analysis,
real-time satellite imagery or input to any network calculation.

The adjacent icons directory contains Phosphor Core 2.1.1 regular icons,
recoloured to NetGravity tokens; shapes are unmodified. MIT licence included.
