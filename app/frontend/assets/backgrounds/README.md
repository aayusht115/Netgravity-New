# NetGravity network atmosphere

`network-atmosphere.webp` is decorative background art, not a map, a view of
the uploaded network, or a source of business information. It is locally
served and requires no image generation service or API key at runtime.

Generated on 2026-09-11 with the built-in ImageGen tool, then encoded to WebP
at quality 86 (1536 × 1024, approximately 25 KB). No geometry, chart assets,
geography, uploaded data, credentials or existing artwork were supplied.
The generated original is retained in Codex's generated-images directory.
Existing Phosphor icons remain under their existing license in `../icons`.

## Generation prompt

Create a polished, understated decorative BACKGROUND ASSET for NetGravity, an enterprise logistics network decision dashboard. Wide landscape aspect ratio, about 3:2. Cool near-white / very pale blue-gray (#f5f8fb) base. An abstract network of ultra-fine gracefully curved transport routes with occasional tiny ring nodes, in muted lavender and dusty teal. Concentrate the network in the RIGHT third, drifting softly toward the upper middle and fading completely into the base color at the left and bottom. At least 70 percent quiet negative space, with the left two thirds especially empty for interface titles and readable data cards to be placed over later. A few tasteful larger arcs suggest global connectivity and gravitational orbits, sophisticated editorial-tech aesthetic, two-dimensional fine-line texture, atmospheric but not blurry. Very low contrast overall yet the detail should still be visible in the upper right. DO NOT draw a literal map, continent outline, real facility network, charts, data, labels, text, logos, buildings, isometric warehouses, icons, UI screens, neon glow, dark background, sci-fi circuits, or busy grids. Flat artwork edge-to-edge, no surrounding frame, no watermark. This is background art, not an app mockup.

## Usage

`css/atlas-theme.css` uses it behind page headings and the spaces between
opaque dashboard cards, with a fade to the page colour. It does not appear
on the Digital Twin map, behind chart data, or in print exports. It has no
animation or interaction, and the interface remains usable if it fails to load.
